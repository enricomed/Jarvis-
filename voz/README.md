# Jingle do modo show

Coloque aqui `jingle.mp3` (ou `jingle.wav`). Ele toca quando você bate duas palmas, antes do Jarvis começar a ouvir.

Dica: 2 a 4 segundos bastam. Pode ser um áudio gravado no ElevenLabs ("Pois não, Doutor. Em que posso ajudar?") ou um som curto.

Os áudios desta pasta não vão para o GitHub.
